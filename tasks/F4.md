# F4 golden harness brief

Base SHA: `fc4949c74abc5ff688fec7188418d2a80bc4347d`.

Allowed files: `tests/golden/**`, `docs/evidence/F4-golden-harness.md`, and `tasks/F4.md` only. The harness is a read-only comparator over synthetic fixtures; it must not modify `stage3-run/`, start production services, or write emulator state.

Done criteria: encode the cited route cases and hashes; normalize only documented volatile fields; detect status, redirect, cookie, selected-header, body-marker, and hash mismatches; include a deliberate mismatch test; pass `gofmt`, `go test ./...`, and `go test -race ./...`.

Stop on live production requests, emulator writes, real data, guessed normalization, schema changes, credentials, moving image tags, secrets, quota/auth/payment failure, or a second failed attempt.

Provisional cap: 60,000 uncached input, 40,000 cached input, 12,000 output tokens, 90 minutes. Record actual model, token/cost/latency metrics, retries, and acceptance. Jev is not justified for this deterministic fixture set.
