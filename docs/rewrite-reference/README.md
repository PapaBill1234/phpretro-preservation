# PHPRetro Rewrite Reference

This directory contains the documentation produced for the PHPRetro-PDO rewrite and preserved with this project.

## Contents

- `PHPRetro-Modernization-Plan.md` - modernization scope and implementation plan.
- `Polaris-Schema-Reference.md` - PolarIS database and ownership reference.
- `docs/PHPRetro-Plain-English-Guide.md` - project and setup guide.
- `docs/phase-reports/` - rewrite phase reports, audits, compatibility notes, and handoff records.
- `references/` - schema additions, plan and guide copies, and extracted implementation notes.

## Provenance

Files were copied from `legacy/phpretro-pdo` on 2026-10-01. The legacy source remains unchanged. These documents are reference material for the preservation project; they do not assert that the rewrite is complete or that every documented feature belongs in the new implementation.
