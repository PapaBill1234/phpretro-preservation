## Deliverable

Implement the first localization boundary:

1. Define supported locale identifiers and deterministic fallback chains.
2. Validate locale catalogs and reject malformed or unsupported versions.
3. Resolve translation keys with explicit missing-key behavior; never silently substitute an unrelated locale.
4. Define typed localized view models for React themes.
5. Ensure locale-varying cache keys include the locale and cannot collide with non-locale keys.
6. Add synthetic TypeScript and Go tests for locale validation, fallback order, missing keys, malformed catalogs, cache-key variation, and unsupported locales.

## Acceptance

- No arbitrary code/template execution from catalogs.
- No locale input changes authorization, route ownership, CSRF, audit, or database ownership.
- Fallback behavior is deterministic and documented.
- Existing frontend and Go checks remain green.
- Evidence records exact synthetic fixtures, unknowns, and commands.

## Stop conditions

Stop on guessed translation schema, production data, CMS mutation, unreviewed dependency, ambiguous fallback semantics, or two materially similar verification failures.
