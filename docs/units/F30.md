F30 - Theme and localization contract extension

fidelity: guessed

What works:
- Preserves the presentation-only theme.v1/home.v1 boundary in
  frontend/src/themeManifest.ts.
- Theme manifests accept only StarterShell, the home.v1 view model, and the
  presentation capability; extra capabilities or view models are rejected.
- Localization catalogs remain data-only with an explicit catalog version,
  supported locale set, and approved message keys.
- Missing message maps, unknown keys, blank messages, unsupported locales, and
  malformed locale shapes are rejected.
- Unknown translation keys do not invent fallback text.

What is guessed:
- The roadmap explicitly says F30 lacks a defensible broad theme/localization/
  CMS scope and source authority. This bounded contract extension therefore
  preserves the existing presentation boundary and uses synthetic validation.
- No CMS, admin, uploads, publication, external assets, or arbitrary HTML was
  added.
